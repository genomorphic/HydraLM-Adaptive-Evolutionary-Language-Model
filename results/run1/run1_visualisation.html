What Happened

Run 1 unfolded in five distinct phases, each driven by the interaction between gradient descent and the evolutionary algorithm.

Context

Bugs Active During This Run

Run 1 predates several fixes. The data is real but these limitations should be understood.

⚠
Shapley not reaching StatsTracker — Cell health showed 0.000 in the inspector. The EA was updating health internally but the values never surfaced to stats.json. Fixed: _evolve() now returns sv_info which pretrain_step() spreads into reward_info.
⚠
Pain in negative range [-1, 0] — Sign convention mismatch with the other three homeostasis scalars. Fixed: pain is now a positive distress level [0, 1]. Values in the homeostasis chart above have been converted.
⚠
Elite fraction 20% → crossover rarely worked — Only ~5 cells were crossover-eligible at max population. With DAG wiring making shape matches rare, most new cells initialised randomly. Fixed: elite fraction raised to 50%.
⚠
No gene pool — All inheritance was from live elite cells only. Pruned cells' weights were discarded permanently. Fixed: gene pool added, persists across checkpoints, three flash modes.
